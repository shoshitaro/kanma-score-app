# 韓麻スコアアプリ

GitHub Pages で公開するための最小構成です。

## ファイル

- `index.html`
- `.nojekyll`

## 公開方法

1. GitHub で新しいリポジトリを作成
2. このフォルダの中身をリポジトリ直下に配置
3. `Settings` → `Pages`
4. `Deploy from a branch`
5. `main` / `root`
6. 保存

数分で公開URLが発行されます。

## メモ

Apps Script 側の URL は `index.html` に入っています。  
Apps Script を更新するときは、既存デプロイを編集して URL を固定する運用がおすすめです。
